# Pantry Pilot

Pantry Pilot — небольшое приложение для домашнего учёта продуктов, сроков годности и будущих покупок.

Проект используется как учебный debugging sandbox: здесь можно тренироваться разбираться в незнакомом React-коде, воспроизводить баги, исправлять их и добавлять регрессионные тесты. Задачи находятся в GitHub Issues.

## Стек

- React
- TypeScript
- Vite
- Vitest и Testing Library
- ESLint и Prettier
- localStorage
- локальный mock API

## Запуск

Требования: Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite.

При первом запуске используются демонстрационные данные. После изменений данные сохраняются в браузере. Отдельный сервер не нужен.

## Команды

```bash
npm run dev
npm test
npm run typecheck
npm run lint
npm run format:check
npm run build
```

Для запуска всех основных проверок:

```bash
npm run check
```

Подробности о ветках, коммитах и Pull Request находятся в [CONTRIBUTING.md](CONTRIBUTING.md).

## Особенности проекта

- Данные сохраняются в `localStorage`.
- Синхронизация работает через локальный имитатор API.
- Имитатор иногда возвращает ошибки, поэтому можно проверять обработку неуспешных запросов.
- Даты вводятся по локальному календарю пользователя.
- Заголовки CSV и внутренние значения категорий и единиц измерения остаются на английском как часть формата обмена данными.

## Работа над задачами

Обычный порядок работы:

```text
Issue → Investigation → Fix → Regression Test → Review → Pull Request
```

Лучше брать задачи по одной, сначала воспроизводить проблему и только потом менять код. Исправления стоит оставлять небольшими и не смешивать их с несвязанным рефакторингом.

Перед созданием Pull Request:

```bash
npm run check
npm run build
```
